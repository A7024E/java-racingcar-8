# java-racingcar-precourse

## 구현 기능 목록

### 입력 기능

- [x] 경주할 자동차 이름
    - [x] 이름은 쉼표(,) 기준으로 구분 한다.
    - [x]자동차 이름의 길이는 5자 이하로 작성 가능하다.
- [x] 시도할 횟수
    - [x] 시도 횟수는 숫자로 만 입력해야한다.
    - [x] 최소 시도 횟수는 1 이상 입력해야한다.
  
### 출력 기능

- [x] 자동차 이름 입력 안내 메세지 출력 기능 구현
- [x] 시도 횟수 입력 안내 메세지 출력 기능 구현
- [x] 경주 실행 결과 출력 기능 구현
- [x] 최종 우승자 출력 기능 구현
- [x] 우승자가 여러명이라면 쉼표(,)로 구분하여 출력하는 기능 구현

### 핵심 기능

- [x] 주어진 횟수동안 경주를 진행하는 기능 구현
- [x] 0 에서 9 사이의 무작위 값이 4 이상이면 자동차가 전진하는 기능 구현
- [x] 경주하는 기능
  - [x] 주어진 횟수동안 레이싱 게임을 진행하는 기능
- [x] 모든 경주가 끝나면 우승자를 계산하는 기능 구현
- [x] 사용자가 잘못된 값을 입력한 경우 `IllegalArgumentException` 을 발생시키고, 애플리케이션을 종료하는 기능


### 예외 사항

- [x] 자동차 이름값을 입력하지않은 경우
- [x] 공백을 입력할경우
- [x] 자동차 이름이 5자를 초과할 경우 
- [x] 시도 횟수를 입력하지 않은경우
- [x] 시도 횟수에 숫자로 입력하지 않은경우
- [x] 시도 휫수가 1보다 작은경우
- [x] 자동차 이름이 중복될 경우
